**Install:** download `GlassPlayer-1.8.0.ipa` below and sideload it.

### Library
- **Title page** for every file: backdrop, poster, title, year, rating, genres, synopsis (episode synopsis for series files), file facts, Resume / Start over, and a 3D **Play** button that tilts toward your finger and follows the device (parallax highlight). Other episodes of the same title are listed underneath
- **View styles** on Home, the All view and the title page: Thumbnails, List, Details (thumbnail + episode title + synopsis). The choice is remembered
- Tapping a tile opens the title page; long-press still plays directly

### Discover / IMDb
- Ratings show one decimal (8.8, not 8.8000000000000007)
- Titles use the English/display name from the page data (The Good, the Bad and the Ugly; Hope — not the original or romanised name); same for details, episodes and anime
- IMDb cache invalidated so the fixed data replaces the old

### Player
- Media info opens in the same spot and size as Live stats (top-left) and morphs into it
- Panels are smaller (340 pt in landscape, tighter rows and type) and pop from their button like the Home "+" menu (scale from 0.2 with a bouncy spring)
- Playlist shows thumbnails and episode names
- Segment pickers (Playlist / Chapters / Markers, Skip interval): the thumb is glass while it moves and takes the accent colour when it settles; drag it across like the tab bar
- Every "›" row (Media info, Commands, Lock controls) is tappable along its full width
- Subtitle size slider capped at 1.6× (2.5× was unusable)
- Volume/brightness capsule is slimmer and slides in from the top edge
