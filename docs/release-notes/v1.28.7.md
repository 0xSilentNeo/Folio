**Test build.** Download `Folio-1.28.7.ipa` below and sideload it. It updates 1.28.6. It's a pre-release until you've checked it on your phone.

A second pass over 1.28.6's fixes, and the Clear pill's morph.

### Search
- **Clear pill:** on iOS 26 it's the system's glass button, which swells under your finger, and "Clear recent searches?" now opens out of the pill (it rose from the bottom of the screen). The list empties with a short animation. Before iOS 26 it's the filled capsule, dimming when pressed.

### Found on re-checking 1.28.6
- **Watch history:** 1.28.6 kept what it could read from a damaged file, but a file cut short has nothing readable, and history still started empty. It now comes back from the daily backup.
- **Expired download links:** the web page was refused, but Folio then retried it as many times as "Retries on error" allows. It now fails once, with the reason.
- **Widgets:** one that can't read Folio's data retries hourly, not every 15 minutes: where nothing can ever be read (an install that gives the widget no access) the shorter wait would have used up iOS's daily refresh allowance. The redraw at launch now only happens when Folio is actually on screen, not on a background launch.
- **Night mode and dialogue boost:** since 1.28.6 they're applied without waiting for the engine, so Folio couldn't tell if the engine refused the audio filter. It checks a moment later and no longer counts a refused filter as on.
