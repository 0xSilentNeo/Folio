### Cast photos
- The page-data search stopped at the object holding `countriesOfOrigin` — which on IMDb's title page is the main title object, where the cast with photos lives — so the photo list was never reached and the four photo-less "Stars" were shown every time
- Now everything is searched and the list with the most photos and roles is used. **Checked** against page data in both shapes IMDb uses (`cast.edges` and `castV2`): photos and roles picked, "Stars" ignored. Your log will show a line like `cast tt…: chose …cast.edges — 15 people, 15 photos`

### The text under the title
- It showed an episode's original title (S1E4's "Tanin ga Shinjitsu o Inpei…") instead of the show's romaji name: it took the first object that referred to the show, and an episode's link back to the show qualified. Now the name and original title come from the object that *is* the title. The same check found that this mistake could also rename the show to an episode's title — fixed too
- Titles already in your library are looked up again the next time you open them

### English episode titles
- From TVmaze when IMDb only has the original-language title: Classroom of the Elite now reads "What is evil? Whatever springs from weakness." … (checked live: 54 episodes found by name; Game of Thrones by IMDb id)
- Settings → General → Episode titles: English (default) / Original language. TVmaze data is CC BY-SA, credited there

### Volume swipes use iOS's own volume indicator
- The volume control the player uses to set the volume was kept "visible" off-screen, which made iOS hide its own indicator — for the hardware buttons too. It's now hidden, so iOS shows its indicator
- Only checkable on a phone (Apple: volume can't be changed in the Simulator). The log says whether it worked; if a hidden control can't set the volume on your iOS, the player falls back to its own indicator automatically
