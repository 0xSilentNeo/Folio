**Install:** download `GlassPlayer-1.3.0.ipa` below and sideload it.

### Player, redesigned
- Three Liquid Glass pills: transport · progress · panels, with close and PiP at the top. Nothing else on screen.
- Panels grow out of their button with a spring: **Tracks** (video / audio / subtitles with checkmarks), **Settings** (speed, hold-to-speed, mode, Enhanced Quality, Anime4K, aspect, spatial audio, boost, delays, skip interval, auto-rotate, screenshots, subtitle size / position) and **Now Playing** (playlist · chapters · markers, save screenshot)
- Panels stay open until you tap away; controls never auto-hide while one is open
- **Anime4K built in**: Mode A, B, C, A+A, B+B, C+A at Fast / Balanced / High quality, switchable live (Settings panel → Video)
- **Enhanced Quality** toggle: mpv's high-quality scaling, debanding and dithering set
- **Boost** (+50 % / +100 %) and Spatial Audio toggle; speed −/+ with the current value
- Smoother: track and chapter reads moved off the main thread, PiP frame readback reduced from every 3 s to on-pause / rare refresh

### Opening files
- The player now runs in its own window, so it can never be blocked by a closing file picker, share sheet or sheet transition
- Everything about opening (picker result, file access, mpv load) is written to the app log
- Paste & Play tells you when the clipboard has no link; the URL sheet accepts dropped links and no longer dismisses by accident while you're typing

### Home
- Rebuilt: greeting + wordmark, Settings and + in glass circles (the Settings tab is gone), Continue Watching hero with artwork and synopsis, Library grid with real posters, source cards with service logos
- Posters, titles and episode names come from a metadata lookup of the file name (cached), like Infuse
- Adapts to landscape and iPad widths: more columns, wider hero, no stretching

### Discover
- One floating glass bar: Movies / Series, Trending · Top Rated · New, Genre (or Year for New)
- Streaming services are a row of logos; each opens its own catalogue. The duplicate Netflix rows are gone

### Network
- WebDAV servers show the service's logo (fetched once, cached); file rows show artwork and clean titles

### Diagnostics
- Settings → Advanced → Diagnostics: app log, crash and hang capture (incl. iOS MetricKit reports), one-tap report zip with credentials removed
