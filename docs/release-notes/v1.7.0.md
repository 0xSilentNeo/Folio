### IMDb behind the bot wall
- 1.6's log showed every IMDb page answered with `HTTP 202 / 1997 bytes`: Amazon's WAF JavaScript challenge. Pages are now loaded through a hidden WebKit view when that happens: it runs the challenge, the real page follows, the embedded data is read from the DOM and the token cookie is reused for plain requests afterwards. Images, fonts, styles and all page scripts except the challenge's are blocked, so a page costs a few hundred KB. Loads are serialised and cached as before
- The log records each path: `HTTP 202 … → web view`, `webkit ok after N nav(s)` — please send the report if Discover is still empty

### Player
- Media Info is a glass card in the app's style; "Show live stats" morphs the card into the live stats card (matched geometry), and the stats card closes with the same spring
- Panels (Tracks / Settings / Now Playing) spring open and closed from their buttons and switch between each other inside the glass, animating their height; the Playlist / Chapters / Markers tabs use the same transition
- Any setting with a value menu opens from the whole row, not just the chevron
- Skip interval segments no longer squash into each other
- Volume / brightness capsule is glass; the centre seek indicator is a compact horizontal pill
- Skipping an intro/outro gives a light haptic and a toast; adding a marker too
