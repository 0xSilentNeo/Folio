**Test build.** Download `Folio-1.22.5.ipa` below and sideload it. It updates 1.22.4 and has everything since 1.22.2. It's a pre-release until you've checked it on your phone.

### Search the page you're on
- **The search button beside the tab bar searches the page it's opened from.** It still opens into the field where it is, with an × that takes you back to that page.
  - **From Home** (or Network): your library's titles, the files on each Real-Debrid and WebDAV server, and what each Plex and Jellyfin server finds. Each one gets its own section, and nothing comes from IMDb.
  - **From Discover:** titles on IMDb and your addons, with your recent searches.
- In 1.22.4 it was one search page for everything, and it looked like Discover's wherever it was opened.
- **No search bars on Network's pages** (a server's folders, "Search all files", Plex, Jellyfin and SMB lists): the button covers them. Home's search brings each server's index up to date when it's due, as "Search all files" did.
- SMB servers have no index, so their files aren't in the search.

### Buttons that went square
- **Settings, Add files and the Downloads pill** now zoom out of their own round shape. They started from a square for a moment, the same as the library's menus before 1.22.3.
- **A download title's ⋯ menu** opens from a circle.

### Loading lines on title pages
- **While a title page loads its episodes** (and in the kids profile, while it checks the rating), a bouncing popcorn and a line take the place of the spinner. The line changes every 2 seconds: "Bribing the projectionist…", "Skipping the “previously on”…", "Shushing row C…" and 24 more, each once before any comes back.
- Nothing shows for the first 0.6 seconds: most pages load sooner, and a line that only flashes would look like a glitch. With Reduce Motion the lines only fade.

### Zoom between tabs (an experiment)
- The page now settles into place from slightly larger, without fading. In 1.22.4 it started smaller, which left the top and bottom of the screen empty for a moment, and the fade made it stutter.

### Fixed after a code review
- A download running in iOS's background session could start again in Folio after a relaunch, downloading the file twice.
- One passing "not right now" from iOS sent every later download of that launch the slower way.
- Quick skips no longer move a position you just chose on the bar.
- Plex results without their file are read whole first, so they play.

### Please check
- The search from Home with your Real-Debrid, Plex and Jellyfin servers. Plex and Jellyfin couldn't be tried here.
- Settings' zoom, and the tab zoom if it's on.
- A slow title page, to see the loading lines.

### Tested
- Simulator (iPhone 17 Pro Max, iOS 26.5): all unit tests (new ones for the search answers, the session downloads and the loading lines) and the UI tests pass, with a new one for the loading lines on a page held back 6 seconds.
- The tab zoom was checked frame by frame in a recording.
- Not tested: Plex and Jellyfin against real servers, anything on a phone.
