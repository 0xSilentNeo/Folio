**Install:** download `GlassPlayer-1.6.0.ipa` below and sideload it.

### Adding files
- "Open file" is gone. **Add files** (the button in the centre of an empty Home, and in the **+** menu) opens the Files browser with multi-select; iOS copies the chosen files into GlassPlayer → Media and they appear in the library immediately. One file starts playing straight away
- Why: the in-place "open" grant is refused for apps signed with a sideloading certificate (same on every sideloaded app on the device); the copy path never needs it
- On iOS 18+ the browser zooms out of the Add files button

### Discover — IMDb built in, Cinemeta removed
- Titles, posters, synopses, ratings, charts, cast and episode lists now come straight from IMDb's own pages — the numbers you see on imdb.com. No key, no third-party catalog
- Trending = IMDb Most Popular; Top Rated = IMDb Top 250 (with a genre: IMDb's user-rating ranking with a minimum vote count you choose); New = the year's most popular; genres incl. Anime (animation from Japan)
- Search uses IMDb's suggestion API (posters, years), plus any installed addon that supports search
- Library tiles resolve filenames through IMDb too
- Configurable in Settings → Discover → IMDb: language, Top Rated minimum votes, Anime definition, cache
- Filter changes no longer flash an empty page; a failed load shows "IMDb didn't answer" with a Retry, and the HTTP status is written to the diagnostics log
- TMDB stays available as an optional source with your own key
- The Cinemeta addon that older versions auto-installed is removed on first launch; addons are only needed for streams now

### Player
- Transport / panel pills are back to the single-pill look; only the press animation of each button remains
- Controls run edge to edge: 20 pt from the screen edges in every orientation, no safe-area gap
- Slimmer chrome: 46 pt pills, thinner progress bar
- Skip intro/outro: seeks are queued asynchronously (a synchronous mpv command could freeze the button for seconds on network files); the button has a larger hit area so a tap near it never reaches the video and toggles the controls; it no longer flickers back while the seek lands
- Scrubbing (progress bar or horizontal swipe) seeks live, so the main screen shows the frame under your finger; the centre seek indicator springs in and out
- Volume swipe sets the device volume (0–100 %, instant, like the hardware buttons) instead of mpv's software gain; the indicator is a system-style capsule at the top centre, shared with brightness
- mpv's stats.lua overlay is disabled and the old saved "Stats overlay" command is dropped; live stats live in Media Info → Show live stats
