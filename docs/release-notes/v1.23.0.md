**Test build.** Download `Folio-1.23.0.ipa` below and sideload it. It updates 1.22.7. It's a pre-release until you've checked it on your phone.

### Search
- **No stall the first time it opens.** Folio asked the field to take focus 0.35 s after iOS had already done it; the first time, the two collided while the keyboard loaded. Measured in the simulator: the longest frame on the first open went from 431 ms to about 100 ms (the rest is iOS loading the keyboard).
- **Its own intro instead of a line of grey text between list separators:** what it searches, and a chip for your library and each server.
- **"On your servers" with a Files / Posters pill.** Files: a row each, with a pill naming the server the file is on; tap the pill to open the folder it's in. Posters: one poster per release, tap to open the release's folder (a file at the top of the server plays). The choice is remembered.
- "Nothing matches" says so in the same style, with where it looked.

### Network had a search bar
- The search field belonged to the whole tab bar, so iOS also put it under Network's title, the only tab with a standard title bar. It's the search tab's own field now: Network has none, and the round search button still opens the field at the bottom.

### When a server lets you down
- A file that doesn't play from a server is checked with the server itself (its first byte, with the player's login), and the card says what happened, in Folio's style:
  - **Real-Debrid removed this file**: the torrent was deleted or taken down. A button removes it from Continue Watching, and Home's row and the search drop it.
  - a refused login, a server that's down (5xx), too many requests, you're offline, or the server can't be reached;
  - or, when the server does send it, that the file itself didn't open.
- A file still opening after 12 s is checked too: a removed file or a refused login ends the wait instead of a spinner forever.
- A stream that stops well before its end (the connection dropped) now says "The stream stopped at 31:00 of 45:00" with Try again and Play next, instead of going on to the next episode as if it had ended.
- A Real-Debrid folder that's gone shows the same card on its page, and a link that arrives without the server's login gets it (your 5 Nov log: a Real-Debrid file opened without it failed with only "loading failed").

### Control Center and the Lock Screen
- **Artwork:** the title's picture (episode still, else backdrop, else poster), found as the library's rows find theirs. Until now only a saved frame, which a file you hadn't stopped before didn't have.
- **The player's Live Activity is gone**, as you asked: Now Playing shows what's playing. One left on the Lock Screen by an older version ends at launch. The downloads activity stays.

### Widgets
- Your install has no App Group (the signing profile lists none), which is how the widgets read Folio's data, so they only said "Open Folio". Now, without an App Group, Folio keeps the widgets' files as small Keychain items in its own Keychain group, which the widget can read when the signing lets an app and its widget share Keychain items. **Whether yours does is not known yet:** the log line "[widget] … the widget last read them: …" says. If the widget can't, it now says "Can't reach Folio" instead of "Open Folio".

### Discover
- Lists go on as you scroll: from IMDb's first 100 to 250 (Trending goes on past the 100 of IMDb's chart in the same popularity order). IMDb gives at most 250 for one list: it ignores every paging setting (checked in the simulator), so the list ends with a line saying so. The Top 250 chart is whole.
- With a TMDB key, a page that repeated titles stopped the grid for good; it goes on now.

### Folio's own loading
- The system spinner is replaced everywhere by the Folio leaf with a light running round it (Reduce Motion: it only breathes).

### Tracking
- Every tracked show is asked again on the first launch of a new version, so what older versions saved (Dragon Ball with Beerus's times, Tulsa King's made-up 11 pm) is worked out again with the current rules.
- Episodes with no known time (TVmaze's stand-in hour): notifications come at 9 in the morning of their day ("comes out today"), the widget and Siri say the day, not an hour.
- Notifications turned on in iOS Settings are planned when you come back, not hours later.

### Code check (line by line, seven areas)
Fixed in this version, among others:
- a crash when a subtitle's language is "-";
- kids profile: a film's queue was the whole library, so autoplay could go on to an R-rated film; an added file played at once; folder pages showed everything; a rating Folio couldn't read (R-18, M18, UA 16+…) was guessed from the genres;
- closing a player and opening another within 0.2 s could leave two playing;
- a stream picked for the next episode could lose to an earlier choice; Try again reused an expired link;
- the diagnostics filter let Jellyfin and Plex tokens and percent-encoded addon keys through; links and search words went to the log;
- a `folio://play` link from any app played at once: it asks first now;
- a finished download whose move failed was deleted and downloaded again;
- folders Real-Debrid removed stayed in the search index;
- "Load subtitle file…" in the player's menu did nothing;
- post-credits scenes counted as credits to skip;
- the skip interval in the player's menu lacked 60 and overwrote the back step; "3 files · 3 files" on the downloads activity; Settings → mpv → Log level did nothing (removed: mpv writes its log at debug detail whatever it's set to).
