**Install:** download `GlassPlayer-1.4.0.ipa` below and sideload it.

### Opening files — found it
The file picker was in multiple-selection mode, so tapping a file only ticked it and waited for an "Open" button that's easy to miss. It's single-select now: tap a file and it plays. (Cancel and selection are logged too.)

### Home
- Sources and Recently Played are gone. Continue Watching is a swipeable row of cards (several visible in landscape), then your Library; with an empty library a short note in the middle explains how to add files
- Settings opens with the system zoom transition from the gear (iOS 18+)

### Network
- Files section removed (your phone's files live on Home)

### Player
- Every button has the same spring press feedback as the Home buttons; segmented controls slide their pill; Now Playing tabs cross-fade
- Panels open smoothly: their size is remembered, no first-frame jump, lighter transition
- Slimmer pills (52 pt) that use the full width; the progress pill stretches between the other two
- Brightness and volume now show as a slim iOS-style edge indicator (left / right) that fades and scales in and out
- Live stats card in the app's own style (Media info → Show live stats), replacing mpv's stats overlay
- Fix for the picture staying cropped/stretched after rotating while paused or switching apps: the renderer is told to redraw at the new size

### Discover
- Top Rated now comes from IMDb's own Top 250 (movies and TV) with rank badges and IMDb ratings; genre filter works on it. Cinemeta's "Featured" list was not a rating chart
