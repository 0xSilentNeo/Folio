### Continue Watching took most of a minute to start
- **What the log shows (11 Nov, 19:45):** the card's link is the addon's playback link (aiostreams), which passes through the addon's own server before Real-Debrid. That server took **34.2 seconds** to answer; Real-Debrid then opened the file in under 4. Folio showed nothing while it waited. The same server timed out twice that day on other requests.
- **Now:** Folio keeps where a stream link led for half a day. On the next play it asks that saved download address and the addon's link at the same time, and plays from whichever answers first. If the saved address no longer works, the link decides as before.
- **And says so:** after 4 seconds of waiting the player shows "Waiting for … to hand over the stream…".
- The first play of a stream still depends on the addon's server.
