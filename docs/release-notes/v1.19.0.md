**Install:** download `Folio-1.19.0.ipa` below and sideload it.

Nothing here is tested on a phone yet. Each section says what was checked in the simulator and what to check. The full round report, with causes, evidence and device test steps, is in the Folio App project.

**Before testing:** turn on Settings → Help & Diagnostics → Diagnostics → **Trace library and images**. It logs picture loads, zoom transitions, Discover requests, the player panel and the library index.

### Search Library keeps its index
- **The index is saved now.** It's kept per server in the app's storage and survives leaving the screen and relaunching. Results show and search at once.
- **Refreshes check only what changed:**
  - a background check runs when the index is over 10 minutes old;
  - a folder is listed again only if it's new, renamed, has a new date/etag, or its listing is over 24 h old;
  - pull down for a full re-index.
- At most 3 folder listings run at once, and one connection per server is reused.
- A quiet status line shows what's indexed and when ("updated 5 minutes ago"), or the progress of a check.
- Removing a server, or changing its address, user name or start folder, clears its index.
- **Please check:** open Search Library twice and after a relaunch; add, delete and rename a torrent. Send the log: the `[webdav] properties …` line shows whether Real-Debrid sends getetag, and `[index] … refresh in N ms` shows the time.

### Posters stay when you go back
- **Cause (simulator trace):** after switching Home's layout, the old layout's row stayed in Home's list as a hidden cell with the same zoom id. Pages zoomed into that hidden row, so it looked like a row card floating over the grid, while the real tile stayed blank.
- **Fixed (untested on device):**
  - zoom ids change with each layout switch;
  - pictures come from one cache, decoded at the size they're shown;
  - tiles show their picture from their first frame.
- **Simulator:** one visible zoom source in every layout after switching; the tile's picture is shown as it comes back.
- The scrambling title text is the intended effect and is unchanged.

### One sort button
- The separate arrow is gone. The sort menu has Recently Added, Name and Size, with the current one checked and its order shown under it.
- Pick the current sort again to turn the order round, as the Files app does (checked on iOS 26.2). The icon has no arrows.
- Home and the WebDAV browser use the same menu.

### Real-Debrid library: posters and clean titles
- **Clean titles now work on release folders.** They show the title, season and year, plus what tells releases apart: resolution, source, HDR, Dolby Vision and group, with codec, audio and more added only when two would still look the same.
- Long-press for the original name and "Copy original name".
- **Posters:**
  - matched with your WebDAV script's scoring, through TMDB when you've set a TMDB key, otherwise IMDb;
  - an unsure match shows the title's initials, never a guess;
  - looked up only for rows on screen, 4 at a time, and stored by IMDb id, so Home and the library share them.
- **Please check:** any wrong poster, with its `[poster]` log line.

### Real-Debrid on Home
- **Where:** the Library shows a Real-Debrid entry, pinned first. It has a collage of your newest releases, the item count and the total size.
- **When it shows:** only when a Real-Debrid server is set up and its last check worked. It's there from the first frame, with nothing added to launch.
- **States:**
  - a refused login or a removed server makes it leave;
  - offline, it stays, marked offline, and its page says so.
- It doesn't count towards the Library number.

### Discover: back button no longer covers the logo
- The provider header now starts below the navigation bar.
- **Simulator:** checked on iPhone 18 Pro, 18 Pro Max and 17e (iOS 27) and iPhone SE (iOS 26.2), at normal and the largest text size, for every provider.

### Sizes for titles on Home
- **List and Details:** titles show their total size.
- **Thumbnails:** titles get a size badge.
- VoiceOver reads the size after the name.

### Playlist opens on the playing episode
- **Cause:** the episode rows' ids clashed with the list's own id, so episode 1 scrolled to the middle.
- **Fixed (untested on device):**
  - the list opens with the playing episode centred and highlighted, with no visible scroll;
  - it follows auto-next and picks;
  - Chapters does the same for the current chapter;
  - rows fade under the tabs instead of being cut.
- **Simulator:** episodes 1, 6 and 10 each opened on screen and marked as playing.
- **Please check:** open the panel on a middle episode and record it.

### Provider pages: Shows/Movies no longer go blank
- **Cause (your log):** switching tabs cancelled the running request, and the cancellation was stored as an empty list for 30 minutes.
- **Fixed:**
  - each tab loads once and keeps its titles and scroll position while you're on the page;
  - coming back shows the last list at once and refreshes behind it;
  - an error shows inline with Retry and never empties the grid.

### Watched menus
- "Mark all as watched" shows only when something is unwatched, and "Mark all as unwatched" only when something is watched.
- The same applies to single episodes, Home's titles and WebDAV files. Menus read the same history as the watched marks.

### Text and Continue Watching
- Episode descriptions and titles decode HTML characters: "O'Hara", not "O&#39;Hara".
- Continue Watching shows one format for every source: "S1 · E24 · episode title". It never shows a release name like "[AnoZu] …".
