### The download crash
- **What happened (10 Nov report):** Folio closed while a download ran, as soon as one of its connections finished, and again on every launch after that, since the download carried on at launch; pausing, cancelling or removing it closed Folio too, as each of those ends its connections. A line added to the log in 1.27.0 (which protocol the server answers over, HTTP/2 here) was passed on from the network's own thread to the download list, which may only be touched on the main thread and checks it: the check ended the app. The tests' stand-in server reports no protocol, so they never reached that line.
- **Now:** the line goes to the main thread like every other download event, and the download list takes any event that comes another way onto the main thread instead of ending the app.
- The Dynamic Island's download activity ended with the crash; it now stays.
- Downloads that were stopped by the crash carry on from what's on disk.

### Tested
