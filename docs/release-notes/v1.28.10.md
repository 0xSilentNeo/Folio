### Engine 4: HTTPS through Apple's encryption
- Streams over HTTPS are now decrypted by Apple's own library (Secure Transport), as Outplayer does, not the engine's bundled GnuTLS. Your 11 Nov report had the stream's download thread at 25–30% of a processor core on a 4K stream; Apple's library uses the phone's encryption hardware.
- Nothing else about streaming changes: seeking, headers and redirects are the engine's as before. SMB is unaffected.
- **Known limit:** Secure Transport speaks TLS up to 1.2. A server that accepts only TLS 1.3 would not play. Real-Debrid and the common hosts accept 1.2; if a stream that played before now fails to open, send a report.
- **Not measured:** the saving is expected, not proven. Play the same 4K stream for the same time and compare.

### Fixes from a check of 1.28.6–1.28.9
- **Saved download address (1.28.9):**
  - It was saved as soon as a link answered. A debrid addon answers a link whose file isn't ready with a short "downloading" clip, which would then have played in the file's place for half a day. It's now saved only once the file has loaded, is on another host than the link, and is at least five minutes long.
  - Try again, and a failed load, forget the saved address, so the link is followed afresh.
  - The saved address must answer as a file does (part of it, not a web page).
  - The "Waiting for the stream's server…" note stays up for the whole wait, not 1.6 seconds of it.
- **Kids profile:** a server-widget write already under way when the profile was turned on could put grown-up titles back on the widget.
- **Diagnostic traces:** each is timed from when it was switched on. One turned off and on again days later would have been switched off at the next launch.
- **Night mode / dialogue boost:** the check added in 1.28.7 could decide the filter was refused when the engine was only busy, leaving it on with the switch off.
- **Downloads:** on a server without resume support, stopping a little later than last time no longer counts as progress.
- **Notification Test** also ends an hour after it was turned on (a full run only ended it if you stayed away for all of it).
- **Settings search:** hidden while Settings is locked by the kids profile; the tab bar is only hidden where it sits at the bottom (not on iPad).
- **Clear pill before iOS 26:** drawn as a capsule again.
- **Log:** the race's cancelled request no longer reads as "link didn't answer".
