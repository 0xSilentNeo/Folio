**Install:** download `GlassPlayer-1.1.0.ipa` below and sideload it (AltStore, SideStore, Sideloadly, TrollStore).

### New engine: Metal + libplacebo
- Video now renders through mpv's gpu-next renderer on Metal (via MoltenVK), the same path desktop mpv uses
- **Dolby Vision** (profiles 5, 7, 8 via libdovi), HDR10 and HLG, with HDR output on EDR displays
- 10-bit video renders correctly (the old OpenGL ES path couldn't)
- Compute shaders now work; the OpenGL ES renderer stays available under Settings → Advanced
- Lua scripting still built in (LuaJIT)

### Audio
- Multichannel output: Dolby Digital / Digital Plus, Dolby TrueHD, **Atmos**, DTS, DTS-HD MA and DTS:X play as 5.1/7.1 to AirPlay/HDMI and as **Spatial Audio** on AirPods (Atmos and DTS:X play their surround channels; object metadata isn't rendered)
- Audio tracks are labelled with their format and channel layout

### Player
- New minimal Outplayer-style controls: plain glyphs, native menus for subtitles, audio, speed and more
- Much faster: position updates no longer re-render the whole UI, and there are no blur layers over the video
- Live scrubbing preview on the seek bar and swipe-to-seek
- **Hold to speed up** with the speed picked right in the player's speed menu
- PiP: returning to full screen no longer shows a distorted frame
- Volume boost up to 150% (swipe on the right edge)

### Fixes
- Files picked with **Open File**, shared from the Files app or opened with "Open in GlassPlayer" now play directly (they no longer need to be copied into the Media folder)
- More file types register with the Files app (MKV, WebM, AVI, TS, FLV, subtitles)

### Settings
- Reorganised into Playback, Subtitles & Audio, Skip Intro, Scripts, Shaders, mpv Config and Advanced
