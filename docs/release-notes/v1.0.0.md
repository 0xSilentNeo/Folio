First release of GlassPlayer, an mpv-based player for iOS 17+.

**Install:** download `GlassPlayer-1.0.0.ipa` below and sideload it with AltStore, SideStore, Sideloadly or TrollStore. The IPA is unsigned.

### What's in it
- libmpv engine (FFmpeg, libass, libplacebo, Lua 5.2) with VideoToolbox hardware decoding
- External **Lua scripts** (`mpv/scripts`, import, install from URL, on/off toggles), `script-opts`, `mpv.conf`, `input.conf`
- **GLSL shaders** with one-tap Anime4K / FSRCNNX downloads and presets, toggled per video
- **Active Picture in Picture**, including auto-PiP when leaving the app (CPU renderer while in PiP)
- **WebDAV** browser (Real-Debrid / TorBox / Premiumize presets) with sort memory, clean titles, progress badges and library search
- **Stremio-protocol addons** (Cinemeta built in): catalogs, search, episodes, streams, addon subtitles
- **Skip intro/outro/recap/preview** from chapters, AniSkip or Open Anime Timestamps, with auto-skip options
- Player controls: gestures, side panels, hold-for-2×, lock, rotation lock, AirPlay, screenshots
- mpv command console and saved command buttons; hardware keyboard forwarding

### Known limits
- Lua scripts can't launch programs (no `subprocess`, curl or yt-dlp on iOS); JavaScript scripts aren't supported
- Compute shaders don't load (OpenGL ES 3.0)
- Raw torrent streams from addons need a debrid-configured addon
- First release: please report anything odd with the log from Settings → mpv → Last playback log
