**Test build.** Download `Folio-1.28.6.ipa` below and sideload it. It updates 1.28.5. It's a pre-release until you've checked it on your phone.

The first fixes from the whole-app review (docs/code-review-1.28.5.md): its ten "fix first" items, the player batch, and the search Clear pill.

### Notifications
- **Test is off.** Notification Test had been on by default since the 1.25.0 test build, and it was on on your phone. While it's on, Folio sends its samples instead of planning real notifications, holds new-episode alerts, and each background refresh started the whole run again. It's turned off once for everyone, and Test now turns itself off after one full run.

### Player
- **Menus and switches don't wait on the engine:** picture mode, night mode, dialogue boost, audio boost, loop, subtitle style, the audio warm-up on play, and reopening audio when AirPods or HDMI connect.
- **Less redrawing:** buffering, speed and subtitle track no longer redraw the whole player when they haven't changed, and the Lock Screen's info is set once after a scrub, not up to ten times a second.
- **Heat:** a video played again from the Lock Screen or AirPods after a pause in the background no longer keeps decoding pictures nobody sees (off after 15 s, as when you leave it playing).
- **Decoder:** after Folio rebuilds the hardware decoder it checks the result once more. "Decoded in software" now shows only when mpv really says so, not for a stream that's slow to start.
- **Now Playing:** rows are built as they scroll into view. Before, every row of a long queue was built, and its picture loaded, just after the player opened. The same file queued twice no longer confuses the list.
- **Controls** hide again after you close Media Info, Live Stats, the console or a menu.
- **Smaller fixes:** a late position from the previous file can no longer bring up Up Next or skip in the new one; history is no longer saved as 0:00 between files; after a memory warning the next episode no longer buffers alongside; the A/V trace runs only with tracing on.

### Search
- **Clear** is a pill in the Recent header, like the search's other pills.

### Posters
- **Cowboy Bebop, for good:** IMDb's popularity rank is kept with the cached answer. In 1.28.5 it was dropped, so the tie-break only worked on a fresh lookup.

### Widgets and Control Centre
- **No more stuck widgets:** a widget that couldn't read Folio's data (before the first unlock after a restart, say) tries again in 15 minutes instead of never. Every widget is also redrawn once each time Folio opens.
- **Resume in Control Centre:** the control now runs Folio's own action, which opens Folio and plays what you watched last. 1.28.4 handed iOS the `folio://` link directly, which iOS evidently drops on an install without universal links. It's a new control: **remove the old Resume, then add "Resume in Folio"**. Folio also asks iOS to redraw its controls each time it opens. If the control still looks blank and its name shows as "Resume in Folio", iOS is drawing its placeholder; send a report.

### Kids profile
- No new-episode alerts while it's on, and a tap on one delivered earlier no longer opens Tracked Shows without the passcode.
- Pick for Tonight and New on Your Server are emptied while it's on (they kept the grown-ups' titles), and filled again when it's off.
- Recent searches are hidden.
- Turning it on also takes back "Tomorrow" snoozes.

### Downloads
- **Expired links:** on the background download path a web page (an expired debrid link's error page) was saved as the video and marked done. It's refused now, as the in-app engine already did.
- **Long downloads:** a network blip no longer uses up a retry for good. After real progress the count starts again, so a few blips hours apart don't fail a file that was downloading fine in between.

### Sharing and history
- **Shared files:** a video shared from Files while Folio couldn't open was lost; Folio offered to "play this stream" with an empty link. It now opens the video.
- **Watch history:** if history.json doesn't read whole, Folio keeps every entry it can, sets a copy aside instead of starting empty and overwriting it, and keeps a daily backup. The same applies to the watchlist.

### Tested
- 536 unit tests pass, including new ones for the cached rank, Test being off, the web-page check, and reading saved lists entry by entry.
- These UI tests pass in the simulator: search (including the new Clear pill), the kids passcode, notifications, Now Playing reopening on the playing episode, the player lock, and the player panels.
- Four panel tests fail in the same way on an untouched 1.28.5, so they're older problems, not this release:
  - three hit a crash in the simulator's own Metal driver as the video engine starts (a real phone uses real Metal);
  - one hits a tile that can't be tapped after cancelling a delete.
- Two stale tests were fixed: the More menu's item name, and Notification Test's row now that Test is off.
- Not checked on a phone: the Control Centre control, and background playback from the Lock Screen.
