**Install:** download `GlassPlayer-1.5.0.ipa` below and sideload it.

### Opening files
- "Open file" now goes through SwiftUI's file importer (single select). If a file still won't react in the picker, the **+** menu has **Import a copy**: iOS copies the file into GlassPlayer → Media and it plays from there — this path works with every provider
- Both paths are logged (picker result / failure) for the diagnostics report

### Player
- Transport and panel buttons are individual Liquid Glass circles that merge into pills, so each button has the system's own press highlight plus the spring press
- Controls use the width: side insets reduced to half the safe area (max 30 pt)
- Brightness and volume indicator is a slim horizontal capsule at the top centre, like the system HUD in landscape
- Live stats card has a title and a close button; the mpv stats-script command is gone

### Discover
- **Fixed:** switching filters while the previous list was still loading left the old items on screen under the new title (that's why Top Rated showed Cinemeta's list and Anime showed a blank page). Filter changes now cancel in-flight loads
- Top Rated reads IMDb's Top 250 (movies and TV) with rank badges
- **Optional TMDB source** (Settings → Discover): add your own free TMDB API key and Discover uses TMDB for Trending, Top Rated, New and genres, with proper Anime filtering (Japanese animation). Titles resolve to IMDb ids when opened, so details and streams keep working
- "Anime" genre added; without TMDB it maps to Animation
- "Configure" only appears for addons that actually have a configure page (Cinemeta doesn't)
