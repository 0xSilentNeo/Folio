### Control Center and the Lock Screen
- **The likely cause of "Not Playing", found in mpv's own code.** When mpv's audio output starts (`ao_audiounit.m`), it sets the audio session again, after Folio's own setup. Unless mpv's `audio-exclusive` option is on, it asks for the session to **mix with others**. iOS never makes an app whose sound mixes with others the Now Playing app (the one Control Center and the Lock Screen show), whatever it publishes. Folio never turned that option on.
- **Measured in the simulator** with a clip that has sound: Folio's setup left the session not mixing ("options 0"), and once the file played it read "options 1", mixing with others. With `audio-exclusive` on, it stays "options 0" while playing.
- 1.22.2's log line read the session before mpv changed it, so it said "options 0" and hid this. A new line, "audio session while playing", reads it once each file plays.
- **What changes for you:** Folio's sound now pauses other apps' sound (Spotify, Music, a podcast) when a video starts, as Music and TV do, and lets them carry on when the player closes. Until now the two played over each other.
