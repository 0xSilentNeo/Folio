**Install:** download `GlassPlayer-1.9.1.ipa` below and sideload it.

### Test build: tune the player UI live
- Player → Settings panel → **More → Tune UI**. Sliders for panel width (% of screen and pt cap), text size, pill height, spring response, spring damping, start scale, blur-while-opening. Everything applies immediately and persists; **Reset** restores defaults; **Replay panel animation** opens and closes Now Playing so you can watch the effect
- The card prints a one-line summary of the current values — copy it into a message and those become the defaults in the next release

### Panel animation
- Replaced the SwiftUI transition (which was not firing — the frame-by-frame showed only the height settling) with an explicit, always-mounted animation: the panel is kept in the hierarchy and its scale, opacity and blur are animated directly from the chosen start scale at the button's position. Switching panels shrinks the old one and grows the new one
- The log records each open with the values used (`[ui] panel open nowPlaying spring=0.55/0.74 from 0.10`)

### Now Playing
- The Playlist / Chapters / Markers picker overflowed the narrower panel (its labels were fixed-size), pushing rows out of the glass; it now shrinks to the available width
