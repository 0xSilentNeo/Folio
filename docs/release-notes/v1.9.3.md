**Install:** download `GlassPlayer-1.9.3.ipa` below and sideload it.

### Library files after a reinstall
- Continue Watching and history stored the absolute container path of a library file; after an install over the previous build that path can stop resolving ("iOS didn't grant access" within 20 ms of `loadfile`). Local items are now re-found under the current Documents/Media by relative path or file name, and watch progress follows the file by name as well
- If a file really is gone, the message says so ("no longer in the library") instead of blaming permissions
- The diagnostics log now records exists / readable / size / data-protection class / number of files in Media for every failed local load
