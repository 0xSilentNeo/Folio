### Panel animation, found
- The reference recording is GlassPlayer 1.3: there the panel visibly *grew* because its glass frame was laid out small (120 pt) and then expanded to the measured content, with the glass following the layout. 1.5 cached panel heights to "remove the delay" — which removed that growth; and on iOS 26 a `scaleEffect` on a Liquid Glass view animates the content but leaves the glass behind (the two copies in the 1.9.1 recording)
- The panel now opens by animating its **frame** from the start scale up to full size (a layout change the glass morphs correctly) while the content scales inside it; opacity ramps in from the first frame so the small bubble is visible as it grows. Closing reverses it; switching panels shrinks the old one and grows the new one
- Tune UI keeps working on it: start scale, spring response and damping all apply to this growth; the blur switch is gone (it caused ghosting)
