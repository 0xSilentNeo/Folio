# Folio brand sources

- `leaf.svg` / `leaf.js`: the leaf on a 100 × 100 grid. `LeafShape` in `App/Sources/Util/Theme.swift` draws the same curve.
- `render.js`: renders the app icons (Folio, Dark, Tinted, Monochrome, Alternative) at 1024 px with Playwright: `node render.js out`.
- `mark.js`: renders the launch-screen leaf (`LaunchMark`, light and dark, @1x–@3x).

Palette: ink `#161514`, graphite `#8B8784`, taupe `#C4B8AA`, cream `#F1EDE6`.
